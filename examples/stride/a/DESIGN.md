# Overview
Calm and legible. Light surfaces for planning and looking back; a dark run surface while running, so numbers stay readable in sunlight and the screen does not drain the battery. Blue carries action.

# Colors
`primary` is for the one action on a screen. `run-surface` is used only on screens shown during a run.

# Typography
Numbers use `font-num` with tabular figures. During a run the main number is `hero`.
