# Context

## Audience
Recreational runners, 3–25 km a week. Most run after work, in the city, with the phone in an armband. Some are training for their first 10 km or half marathon.

## Vocabulary
| Term | Meaning | Never say |
|---|---|---|
| Run | One recorded activity, start to finish | workout, session, activity |
| Pace | Minutes per kilometre, `5'42"` | speed, when we mean pace |
| Split | One kilometre of a run | lap (a lap is a manual split) |
| Weekly goal | Kilometres the runner chose for the week | KPI, mission |

## Constraints
Screens during a run are read at arm's length, in sunlight, while moving. One number at a time, as large as it can be.
