# Flow: record a run

1. **start** — runner picks a goal (free, distance or time), sees GPS is ready, taps Start.
2. **countdown** — 3-second countdown; GPS keeps locking while it runs.
3. **active** — live distance against the goal, current split, time and pace. Pause happens in place on this screen; ending needs a long press.
4. **summary** — run is saved automatically; runner sees totals, splits and the route, and can share.

Changed from 1.0: the separate paused screen is gone (ADR 0001), and Save is no longer a step.
